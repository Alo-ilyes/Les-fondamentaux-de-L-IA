🧩 1. Présentation du TP

L'objectif de ce TP est de mettre en place un pipeline de Machine Learning complet sur le dataset "Iris". Nous comparons une Baseline (Decision Tree) avec un modèle plus robuste (Random Forest), tout en analysant l'overfitting et l'explicabilité du modèle final.

📊 2. Réponses aux questions techniques

Étape 1 : Exploration des données

  • Dataset équilibré ? Oui, les 3 classes sont parfaitement réparties.
  • Valeurs manquantes ? Aucune valeur manquante détectée.
  • Variables discriminantes ? Ce sont les dimensions des pétales (longueur et largeur) qui permettent le mieux de séparer les espèces.

Étape 2 & 3 : Modélisation et Évaluation

  • Baseline ? Cruciale pour avoir un point de comparaison. Ici, le Decision Tree est déjà très performant (~96% d'accuracy).
  • Random Forest vs Decision Tree ? Sur ce dataset simple, la différence est minime, mais le Random Forest offre une meilleure robustesse théorique.
  • Accuracy vs F1-score ? L'accuracy est globale, le F1-score est plus précis pour évaluer la performance par classe, surtout si elles sont déséquilibrées.

Étape 4 : Sur-apprentissage (Overfitting)

  • Observation ? L'overfitting apparaît clairement quand la profondeur augmente : le score train atteint 100% mais le score test décroche.
  • Validation Croisée ? Elle permet de valider la stabilité du modèle sur plusieurs découpages des données.

💡 4. Mes 3 insights majeurs

🚀 Insight 1 : La Performance OUI, La Simplicité AUSSI !

Observation : La baseline simple performe aussi bien que le modèle complexe.
Implication : Ne pas sur-complexifier si une solution simple suffit.

🧠 Insight 2 : Le Piège à éviter (Overfitting)

Observation : À partir de max_depth=5, le modèle commence à mémoriser au lieu d'apprendre.
Implication : Brider la profondeur pour garantir la généralisation.

⚖ Insight 3 : L'importance de l'explicabilité

Observation : SHAP confirme que petal_width est le critère décisif.
Implication : Indispensable pour valider les biais et la logique métier de l'IA.
