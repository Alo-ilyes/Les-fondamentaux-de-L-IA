🔍 3. Analyse de Confusion

En Cybersécurité, le Recall est vital. Notre modèle Random Forest minimise les "Faux Négatifs" (attaques non détectées), assurant une couverture maximale du périmètre réseau.

Les attaques de type DoS sont détectées avec une précision quasi-chirurgicale grâce aux variables de volume (bytes).

👁️ 4. Signatures d'Attaques (SHAP)

Quelles sont les caractéristiques réseau qui trahissent une intrusion ?

L'importance SHAP révèle que src_bytes et count sont les signaux les plus forts. Une anomalie dans ces flux déclenche instantanément l'alerte.
