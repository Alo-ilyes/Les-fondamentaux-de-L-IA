# 🎓 Projets Intelligence Artificielle (B3)
> **Auteur :** Ilyes Alouata | **Formation :** Bachelor 3 IA

Ce dépôt regroupe les travaux pratiques réalisés dans le cadre du module "Les fondamentaux de l'IA". Chaque dossier est autonome et contient son propre code source, ses visuels et un rapport interactif premium.

## 📁 Sommaire des Projets

### 1. [TP1 - Classification Iris](TP1-Classification-Iris/)
*   **Objectif** : Analyse comparative entre Decision Tree et Random Forest.
*   **Livrable** : Rapport standalone avec analyse d'overfitting et explicabilité SHAP.

### 2. [TP2 - Détection d'Intrusions Cyber](TP2-Detection-Intrusions-Cybersecurite/)
*   **Objectif** : Détection proactive d'attaques réseau (Dataset NSL-KDD).
*   **Livrable** : Comparaison multi-modèles (XGBoost, RF, LogReg) et conformité AI Act.

### 3. [TP3 - Deep Learning Fashion-MNIST](TP3-Deep-Learning-Fashion-MNIST/)
*   **Objectif** : Classification d'images Zalando via Réseaux de Neurones Convolutifs (CNN).
*   **Livrable** : Diagnostic des courbes d'apprentissage et visualisation de l'œil du CNN (filtres/activations).
